DevoxxGenie is an open-source LLM code assistant for JetBrains IDEs, built by Devoxx. This map covers the IntelliJ plugin (Java sources; the Kotlin Compose chat UI and inline-completion entry point are not scanned) and the Docusaurus documentation website. Tests, diagnostic CLIs (RagCli, WebSearchCli) and docs build scripts are excluded as development tooling.
